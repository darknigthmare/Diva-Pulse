# DIVA PULSE V10 FINAL — AutoMap + MMD Director

1. Ouvrir `DIVA_PULSE_JOUER.html` directement, ou utiliser `LANCER_WINDOWS.bat` / `LANCER_MAC_LINUX.command` avec Python 3.
2. Importer une musique : AutoMap peut créer EASY, NORMAL, HARD, EXTREME et EX EXTREME comme une famille cohérente.
3. Importer un pack MMD local contenant au moins un PMX et, si souhaité, plusieurs VMD/VPD/textures.
4. Ouvrir **MMD DIRECTOR · PV AUTO** pour choisir jusqu'à quatre PMX, leurs motions et générer un spectacle depuis les sections musicales.
5. Exporter régulièrement la bibliothèque `.pulsepack`, surtout si le stockage du navigateur est indiqué TEMPORAIRE.

Les assets MMD restent soumis aux licences de leurs auteurs. Aucun modèle Vocaloid, morceau ou PV propriétaire n'est redistribué dans cette archive.
