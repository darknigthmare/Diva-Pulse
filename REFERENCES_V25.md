# Références techniques V25

Modules V25 écrits pour ce projet ; aucune dépendance externe n’est téléchargée à l’exécution.

- W3C — Web Audio API 1.1 : https://www.w3.org/TR/webaudio/ — AudioBuffer, getChannelData et décodage. La nouvelle analyse ne prétend pas reconnaître des phonèmes.
- W3C — Web Locks : https://www.w3.org/TR/web-locks/ — contexte de la réservation d’écriture V24 conservée ; la persistance native n’est pas validée dans cette session.

Les formes de fichier `.pulsebundle` et `.pulseface.json`, le calcul d’enveloppe, les protections de morphs et leurs tests sont documentés dans cette livraison. Les références des composants précédents demeurent dans les documents historiques ; elles ne constituent pas une certification de compatibilité universelle.
