# DIVA PULSE V22 — MMD Surfaces & Motion Sync

Jeu HTML autonome : ouvrir `DIVA_PULSE_JOUER.html`, ou utiliser le lanceur local avec Python 3. `index.html` est identique. Aucun CDN, compte ou clé API nécessaire.

Guide actuel : **README_V22.md**. Résultats exécutés : **RAPPORT_V22.md** et **qa/v22/**. Notes techniques : **docs/V22_TECHNIQUE.md**. Les rapports antérieurs sont historiques.

Nouveautés : sous-ensemble des morphs UV/matériaux PMX, support des VMD à morphs seuls dans le diagnostic et Auto Show, calage optionnel sur la pulsation avec BPM source fourni, protection des pistes manuelles et conservation du calage dans les sauvegardes.

Le moteur ne détecte pas le BPM d’un VMD quelconque et ne promet pas une compatibilité MMD universelle. Les limites restantes sont listées dans le guide.

Exporter sa bibliothèque avant migration et avant fermeture si **TEMPORAIRE** est affiché. Google Drive stocke la livraison : télécharger les fichiers pour jouer. Ce dépôt n’est ni un hébergement Web ni une synchronisation automatique de la bibliothèque du navigateur. Aucun site distant n’est modifié.
